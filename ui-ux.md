# UI/UX

## Design Language

- Clean, minimal, developer-focused.
- Dark mode is primary; light mode is supported.
- Neutral base (`zinc` / `gray`), blue accent, red destructive, green success.
- No heavy animations.

## Public Auth Pages

### Sign-In

- Email and password.
- Google OAuth.
- Forgot password link.

### Sign-Up

- Email, password, and confirmation.
- Password strength.
- Google OAuth.

### Forgot or Reset

- Standard email submission form.
- New password form.

### Consent

- App name.
- Requested scopes.
- Authorize and Deny buttons.

### OAuth Callback

- Loading state.
- Error handling.
- Success redirect.

## Admin Panel

### Admin Login

- Email and password fields.
- On success, show TOTP prompt if 2FA is enabled.
- TOTP prompt: single 6-digit input with auto-focus, auto-submit on 6 digits, and paste support.
- "Use backup code instead" link.
- On success, redirect to the admin dashboard.

### Admin Dashboard

- Stats cards for total users, total OAuth clients, active clients, and logins in the last 24 hours.
- Recent sign-in activity table for the last 20 sessions.
- Quick actions for "Register new client" and "Enable 2FA" if not enabled.

### OAuth Client Management

- List view: client name, `client_id`, status, and actions for edit or delete.
- Create or edit form: client name, redirect URIs, allowed origins, skip consent, and enable end-session.
- On create, `client_id` and `client_secret` are shown once in a modal with copy buttons. Warning required.
- Delete uses a confirmation modal requiring the client name to be typed.

### 2FA Setup Screen

Prerequisite check: password re-verification if the session is older than 5 minutes.

- QR code display: large, scannable QR code generated by Better Auth `twoFactor` plugin.
- Manual key in monospace below the QR.
- Instructions: scan with Google Authenticator, Microsoft Authenticator, Authy, or 1Password.
- Verification: 6-digit input with auto-submit on 6 digits.
- Backup codes: on successful verification, show 10 backup codes in a grid.
- Download button saves a `.txt` file.
- "I've saved my codes" checkbox and "Finish" button.
- 2FA status indicator: "2FA Enabled" badge with "Disable 2FA" option.

## Frontend Architecture

- React 19 + Vite + React Router v7.
- Static build, deployable to any static host.
- Decoupled from API, so the self-hoster can replace the frontend if it calls the same API endpoints.
- Route guard (`AdminRoute.tsx`) is UX-only. Server-side `requireAdmin` is the real gate.
