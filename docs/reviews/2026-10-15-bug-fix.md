## Minor
### 🟡 Deduplicate frontend `deriveOrigins` helper, `frontend/pages/admin/RegisterAppModal.tsx:106` and `frontend/pages/admin/EditAppModal.tsx:91`
**Problem**: The `deriveOrigins` helper function is declared independently with identical logic inside both `RegisterAppModal.tsx` and `EditAppModal.tsx`.
**Why it matters**: While the logic is compact and self contained, having duplicate implementations increases maintenance overhead if origin parsing rules evolve (for example, handling edge cases or ports).
**Suggested fix**: Extract `deriveOrigins` into `frontend/lib/security.ts` alongside existing URL validation helpers like `validateUri`, and import it into both modal components.
