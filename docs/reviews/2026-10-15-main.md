## Minor
### 🟡 Add administrative audit logging on role scoping changes, `backend/src/utils/admin-sync.ts:220`
**Problem**: In `backend/src/utils/admin-sync.ts`, `syncAppAdminIdentity` and `removeAppAdminIdentity` perform direct database mutations when re pointing `scopedClientId` to surviving clients or demoting an administrator to standard user status.
**Why it matters**: While the database updates are correct and resilient, tenant administrator changes lack structured audit log entries in `admin_audit_logs`, making forensic investigation of administrator role reassignments more difficult.
**Suggested fix**: Call `recordAdminAudit` or emit a structured audit log entry when an application administrator is synced, re pointed, or demoted.

### 🟡 Standardize test runner script in root package.json, `package.json:8`
**Problem**: Root `package.json` registers convenience scripts for development and security checks, but relies on sub directory prefixes (`npm --prefix backend run test:admin-scoping`) for executing specific unit test suites.
**Why it matters**: Running all unit test suites from the monorepo root requires chaining four separate package commands.
**Suggested fix**: Add a convenience script `"test:unit": "npm-run-all2 test:admin-scoping test:runtime-resilience test:gateway-pipeline test:dev-isolation"` in `backend/package.json` and mirror it to the root manifest.
