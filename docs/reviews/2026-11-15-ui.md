## Resolved Findings

### Resolved: Missing CORS Expose-Headers for Pagination Metadata (backend/src/middleware/cors.ts)
- **Status**: Resolved
- **Resolution**: Added `Access-Control-Expose-Headers: X-Total-Count, X-Page, X-Limit, X-Total-Pages` to `applyCorsHeaders` in `backend/src/middleware/cors.ts`. Verified in `MFA-11` integration test.

### Resolved: Bind MFA Membership Writes to Validated OAuth Context (backend/src/routes/auth.ts)
- **Status**: Resolved
- **Resolution**: Both `/two-factor/verify-totp` and `/two-factor/verify-backup-code` now validate server-side pending OAuth transactions via `resolveValidatedMfaOauthContext(c)`. Membership writes to `user_app_registrations` require completed session verification, client active/public status, and super admin exclusion. Query or cookie tampering fails closed. Tested across 18 security assertions in `consumer-mfa-continuation.test.ts`.

### Resolved: Remove Remote Font Dependencies (frontend/index.html)
- **Status**: Resolved
- **Resolution**: Removed remote Google Fonts, Fontshare, and Material Symbols stylesheets and preconnects. Typography is completely self-hosted using `@fontsource-variable/geist` and `@fontsource-variable/geist-mono` bundled into build assets.

### Resolved: Reconcile Button Variants with Semantic Theme Tokens (frontend/components/ui/button.tsx, frontend/src/index.css)
- **Status**: Resolved
- **Resolution**: Defined semantic hover and active tokens in `:root` and `.dark` mapped through Tailwind `@theme inline`. Removed hardcoded dark overrides and undefined classes (`tomato-hover`, `tomato-active`, `error-container`). Recomputed contrast pairs: light mode accent 4.66:1, dark mode accent 5.89:1, exceeding WCAG AA requirements.

### Resolved: Repair Active Documentation References (frontend/AGENTS.md)
- **Status**: Resolved
- **Resolution**: Updated `frontend/AGENTS.md` to reference root `AGENTS.md`, `docs/SECURITY.md`, and `docs/ARCHITECTURE.md`. Archived legacy notes are pointed to `docs/archive/legacy/`. Added automated broken markdown link verification in `backend/scripts/check-security-doc-consistency.ts`.

## Open Gaps (Non-blocking / Deferred Optimizations)

### Open: Unbounded Sub-Pipeline Lookup on Active Sessions (backend/src/routes/admin.ts:456)
- **Status**: Open (deferred optimization)
- **Problem**: `unmappedSessionPipeline` executes `$lookup` into `auth_events` across active sessions to filter unmapped sessions.
- **Impact**: In ultra-high concurrency environments with tens of thousands of active sessions, query latency could increase.
- **Recommended Follow-up**: Add date-range boundaries or an index on `createdAt: -1` when scaling beyond initial production tiers.

### Open: Clamping of Active Page Index on Filter Reduction (frontend/pages/admin/AdminLogs.tsx)
- **Status**: Open (minor UX nit)
- **Problem**: When log filters reduce total items below current page index, page displays empty until manually clicking page 1.
- **Recommended Follow-up**: Add an effect in `AdminLogs.tsx` to reset page to 1 whenever totalPages drops below current page.
